F.2 议价空间（Cdiscount 招商内部经验）

  • 佣金 15% 默认 → 头部品牌可谈到 8-10%（参考 Amazon Brand-owner deal 行业惯例，Cdiscount 招商有同等弹性）
  • 月租可减免 3-6 个月新店 onboarding window，年 GMV 承诺 €100K+ 可争取
  • FBC vs 自发货 break-even：单 SKU 月销 30 单+ 且单件 €30+，FBC 才划算；mobile rigs/麦克风类小件高价值通常达标，三脚架大件慎用
🎯 5 条 actionable 谈判建议（ULANZI / SIRUI / Tilta / Saramonic 类）
  1. 打"marketplace 空白 + 创作者红利"组合拳：法国 348K 变现创作者 + 25M TikTok 用户，目标品牌在 Fnac/Darty 都靠经销商，没有官方店——意味着定价权和品牌叙事在别人手里。Cdiscount 给的是官方旗舰位 + 1600 万 UV + 直触创作者群体，论据是数据不是口号。
  2. EPR/VAT 一站式服务做差异化筹码：卖家最怕被 Amazon block（€100K 罚款 + listing 数月下线）。Cdiscount/Octopia 如能打包 EPR 注册 + DEEE/Triman 代申报，比 Amazon "你自己搞" 强一截。这是非价格谈判杠杆。
  3. 佣金给到 8-10% 换品牌方 SKU 深度：ULANZI/SIRUI 全 SKU 上架（100+ SKU）远比挑 20 个爆款值钱——长尾撑搜索权重。明牌话术："15% 是给中小卖家的，您是品牌方，我们走 10%，但要求全 SKU 接入"。
  4. 婚礼/独立摄影师 B2B 通道做品类锚点：法国独立摄影师 30K+ + 婚礼摄影欧洲 €7-8B（30% × 26B），SIRUI 三脚架/灯光走 Cdiscount Pro（B2B 子站）撬专业客户，比 Amazon 散户客单价高 3-5 倍——这是 Amazon 没有的 B2B 通道。
  5. 月租 3-6 个月减免 + 首单流量包：新品牌进入 marketplace 最大焦虑是"我投了开店成本但没流量"。月租减免 3-6 个月 + 首批 SKU 进 Cdiscount 站内 push 列表（节日/Soldes/D-Day），让品牌方算账"零下行风险"。配合 KPI："3 个月 GMV €30K 达成则续 3 个月"，给自己留退路。

F.3 数据使用警示

  1. Mobile rigs / smartphone cages 和 DSLR cages 没有独立 TAM 报告，行业归入"camera accessories"伞下；ULANZI/SmallRig 的体量得通过单店爬虫（Amazon BSR + Cdiscount ASIN）反推。
  2. 法国独立摄影师精确数（不是 INSEE 7420Z 估算）需付费拉 BusinessCoot 报告。
  3. 议价空间 8-10% 是行业惯例 + Octopia 内部经验整合，不是公开数据，对外谈判不能直接引用。
  4. 「主要玩家市占率」全球研报只到品牌层级，不出 % 数字——marketplace 渗透是站内 ASIN 搜索 + 主观判断，非市场调研口径。
